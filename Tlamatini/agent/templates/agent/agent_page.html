          Config · Micrófono

          Configuración del micrófono

          Elige qué pasa después del dictado. Usa el micrófono de la computadora donde corre Tlamatini.

          Cuando la voz se convierte en texto

          Cargando los dispositivos de input…

          100% conserva el nivel original. Sube con cuidado una voz baja: una ganancia alta puede distorsionarla. Esto no cambia el volumen del sistema.

          Una ventana de silencio más larga permite pausas más largas. La grabación siempre termina al llegar al límite.

          Un umbral manual más bajo capta voces más bajas; uno más alto ignora más ruido de fondo.

          Reconocimiento y captura avanzada

          Un beam size mayor puede mejorar el reconocimiento y tardar más. La traducción depende del modelo de voz elegido. Configura el motor y el modelo de voz en Config → Modelos → Voz.
